# FiveM Inventory System

A robust inventory system for FiveM servers using ESX.

## Features

- Player inventory management with ESX integration
- Database storage for persistent inventory data

## Requirements

- FiveM server
- ESX framework
- MySQL database

## Installation

1. Download the script files.
2. Place them in your FiveM server's resources folder.
3. Add `start inventory` to your server.cfg file.
4. Import the database.sql file into your MySQL database.

## Usage

- Players can open their inventory by using the `/inventory` command.

## Configuration

- Adjust the inventory size and default items in the `config.lua` file.
